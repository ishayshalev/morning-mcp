# מה נבדק

הבדיקות מפעילות את שרת ה־MCP דרך stdio עם מפתחות פיקטיביים ו־API מדומה. כל בקשת רשת של שרת הבדיקה נחסמת או נענית מקומית. אין שימוש במפתחות שלכם ואין פעולה בחשבון מורנינג אמיתי במהלך הבדיקות האוטומטיות.

- כל 28 הקריאות ו־27 הפעולות העסקיות בקטלוג.
- הכנה נשארת ללא כתיבה. כלי הביצוע פועל ישירות, ללא חלון אישור MCP או קוד מוקלד, גם בלקוח ללא תמיכה בטפסי אישור.
- הוראות השרת מחייבות את הסוכן להציג סיכום קריא ולחכות לאישור בצ׳אט. מצב החיבור ובקשות מוכנות מציינים במפורש שאין אימות אנושי בשרת. הבדיקות אינן מוכיחות שהסוכן אכן המתין לתשובה.
- סקירה בעברית: פרטי מסמך, לקוח, סכום, נמענים ושינויים, ללא JSON או hashes. פרטי תשלום רגישים מוסתרים בסקירה.
- חסימת שינוי תוכן, כותרת, תאריך, PDF, קובץ הוצאה או חיבור אחרי ההכנה.
- בקשות מקבילות משני תהליכים מבצעות לכל היותר פעולה אחת. אחרי תוצאה לא ודאית, הבקשה נשארת חסומה גם בהפעלה מחדש.
- טופס ההגדרה: שמירה פרטית, אישור החלפת מפתחות, חסימת אתר אחר, תפוגה ושגיאות שמירה.
- שמירה ועדכון מיידיים של טיוטת מסמך, קריאה, חיפוש ותצוגת PDF.
- הפקה מהטיוטה השמורה: קישור draftId, בדיקת תוכן ונמענים, חסימת עריכה אחרי הכנה וסירוב להשמיט שדות כספיים לא מוכרים.
- MCP זמין לפני הזנת מפתחות וטוען מפתחות שנשמרו בלי הפעלה מחדש.

נבדקו הפרוטוקולים 2025-06-18, 2025-11-25 ו־2026-07-28. אין דרישה ל־MCP elicitation. אפליקציית הסוכן עדיין יכולה להציג בקשת הרשאה משלה לכלי.

78 בדיקות עברו ב־macOS. בדיקות GitHub רצות גם ב־Linux, עם Node 22 ו־24. תלויות הייצור לא השתנו מהבדיקה ב־7 באוקטובר 2026, שבה npm לא מצא חולשות ידועות.

## הרצה

מתוך תיקיית המאגר, אחרי התקנת התלויות:

<pre dir="ltr"><code>npm ci --ignore-scripts
npm run check
npm test</code></pre>

בדיקות טופס ההגדרה פותחות שרת זמני ב־127.0.0.1. צריך לאפשר גישה ל־loopback אם סביבת הפיתוח חוסמת אותה. הנתונים נכתבים לתיקייה זמנית ונמחקים בסיום.

## בדיקה חיה ב־7 באוקטובר 2026

בגרסה 0.1.4 נבדקו דרך MCP ו־API עם מפתח עסקי רגיל: אימות, שמירת הצעת מחיר פיקטיבית של ₪1, קריאה חוזרת, עדכון, ניסיון חוזר עם אותו מפתח בקשה ללא יצירת עותק, חיפוש, PDF והכנת בקשת הפקה מקומית. הטיוטה נשמרה במורנינג. החיפוש הציג אותה אחרי השהיה קצרה.

לא הונפק מסמך, לא נשלח מייל, לא בוצע חיוב ולא הועלתה הוצאה. שינוי זרימת האישור בגרסה 0.1.5 נבדק מול API מדומה; לא בוצעה כתיבה חיה כדי לבדוק אותו. כשהמשתמש יבקש לבצע פעולה, הסוכן צריך להציג סקירה ולחכות לאישור בצ׳אט.

המפרט הציבורי של [Morning](https://developers.morning.co/docs/openapi.bundled.json) נבדק ב־7 באוקטובר 2026: גרסה 2.0.0, עם 54 פעולות. נוספו 7 פעולות לטיוטות מסמכים שנצפו בקוד הציבורי של האפליקציה, בנפרד מהמפרט. [כיסוי מלא והחריגים](../API-COVERAGE.md).
