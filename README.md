<h1 dir="rtl" align="right"><span dir="ltr">morning (green invoice) mcp</span></h1>

<p dir="rtl" align="right"><span dir="ltr">mcp</span> למערכת ניהול חשבונות מורנינג (לשעבר חשבונית ירוקה)</p>

חיבור מקומי בין מורנינג (חשבונית ירוקה) לסוכני AI כמו Codex ו־Claude. כל משתמש מתקין במחשב שלו ומחבר את מפתחות ה־API של החשבון שלו. אין הרשמה נוספת.

## מה אפשר לעשות?

- לחפש לקוחות, חשבוניות והוצאות.
- לשמור טיוטות של חשבוניות ומסמכים במורנינג, לערוך אותן ולהציג PDF לפני הפקה.
- להפיק ולשלוח את המסמך רק אחרי אישור שלכם.
- להעלות קבלות והוצאות מקובצי PDF, JPEG או PNG עד 20MB.
- ליצור ולעדכן לקוחות, פריטים ופרטים נוספים דרך ה־API.

הסוכן שומר טיוטה אמיתית במורנינג, בלי להפיק או לשלוח אותה. הסוכן מציג את הפרטים ואת ה־PDF, שואל בצ׳אט אם להפיק וממתין לתשובה שלכם. אם ערכתם את הטיוטה במורנינג, צריך להכין בקשת הפקה חדשה. גם לפני העלאת הוצאה, מחיקה או שינוי אחר, הסוכן צריך לבקש אישור בצ׳אט. זו הנחיה לסוכן, לא חסימה של אישור אנושי בשרת. השרת עדיין בודק שהתוכן לא השתנה ומונע ביצוע כפול. [רשימת הפעולות והחריגים](API-COVERAGE.md).

## 1. מתקינים בעזרת הסוכן

מעתיקים ל־Codex או ל־Claude Code שמותקן במחשב:

<pre dir="ltr" align="left"><code>Install Morning MCP and connect it to the agent we're using:
https://github.com/ishayshalev/morning-mcp

Read docs/INSTALL-AGENT.md and follow its instructions.
Open the local setup page. I will paste my Morning API key ID and secret there myself.
Do not ask for keys in chat or read the credentials file.
Do not enable automatic approvals.</code></pre>

צריך macOS או Linux, ‏Node.js 22 ומעלה ו־Git. הסוכן יעזור להתקין אם חסר משהו. אפשר לחבר גם Claude Desktop ולקוחות MCP מקומיים אחרים. אין צורך בתמיכה בחלון אישור MCP. הסוכן מבקש אישור בצ׳אט; האפליקציה שבה עובדים עשויה לבקש גם הרשאה משלה לכלי.

## 2. יוצרים מפתח במורנינג

פותחים **[אזור אישי ← כלים למפתחים ← מפתחות API](https://app.greeninvoice.co.il/settings/developers/api)**. לוחצים על **+**, נותנים שם, קוראים ומאשרים את התנאים ושומרים.

מעתיקים את **מזהה המפתח** ואת **המפתח הסודי**. הסוד מוצג פעם אחת בלבד, מיד אחרי יצירת המפתח. [הרשאות ומסלולים במורנינג](https://www.greeninvoice.co.il/help-center/generating-api-key/).

## 3. מדביקים ומתחילים

הסוכן יפתח עמוד הגדרה מקומי בדפדפן. מדביקים **מזהה מפתח** ו־**מפתח סודי**, ולוחצים **שמירה וחיבור**. אין עוד הגדרות. אחרי השמירה תופיע הודעת **המפתחות נשמרו**. אם השמירה לא הצליחה, הטופס יציג שגיאה.

המפתחות נשמרים במחשב שלכם. לא מדביקים אותם בצ׳אט. אם העמוד לא נפתח, הסוכן ייתן קישור מקומי; הוא תקף לעשר דקות.

<details>
<summary>איפה מדביקים את המפתחות?</summary>

![הטופס המקומי עם שני שדות ריקים למזהה ולסוד](docs/screenshots/04-local-setup.jpg)

חוזרים לסוכן ואומרים שסיימתם. הוא יבדוק שהחיבור למורנינג עובד. אם הכלים עדיין לא מופיעים בסוכן, מחברים מחדש את ה־MCP. אפשר לבקש:

> תכין טיוטת חשבונית ללקוח הזה על הפרויקט האחרון.

> תכין את הקבלות בתיקייה הזאת להעלאה למורנינג.

טיוטת מסמך נשמרת במורנינג מיד. כשמחליטים להפיק, בודקים את ה־PDF והנמענים ועונים לסוכן בצ׳אט. טיוטת הוצאה שנוצרה מהעלאת קובץ משלימים במורנינג.

## פרטים חשובים

זה עדיין MVP. נבדקו הכנה ללא ביצוע, חסימת בקשות כפולות ושינוי טיוטה. האישור בצ׳אט תלוי בסוכן, והשרת אינו יכול לאמת אותו. שמירה, עדכון ותצוגת טיוטה דרך ה־API נבדקו בחשבון אמיתי. הפקה חיה עדיין דורשת בדיקה כשבאמת רוצים להפיק מסמך. [מה נבדק](docs/TESTING.md). המפתחות נשמרים בקובץ מקומי פרטי ללא הצפנה; בקשות האישור והקבצים המקומיים אינם נמחקים אוטומטית. אין להגדיר אישורים אוטומטיים.
